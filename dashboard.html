Technology Breakdown & Roles

Carefully chosen, lightweight modern web technologies that deliver a 60fps cinematic experience without heavy framework bloat.

Three.js r128

WebGL 3D Interactive Canvas

Powers the hero background 3D particle galaxy. Creates over 1,000 animated particles with light trails reacting dynamically to mouse movement. Implements requestAnimationFrame throttling, delta capping, and automatic pause on hidden browser tabs to maximize battery life and CPU efficiency.

BufferGeometry PointsMaterial WebGLRenderer Tab Visibility API

GSAP 3.12 + ScrollTrigger

Cinematic Motion Choreography

Orchestrates staggered card reveals, metallic line expansions, timeline waypoint activations, and luxury heading entrances. Features defensive fallback: if GSAP fails to load from CDN or JavaScript is disabled, pure CSS animations seamlessly take over with zero visual breakage.

ScrollTrigger Timeline Orchestration Stagger Animations Graceful Fallback

Lenis Smooth Scroll

Butter-Smooth Kinetic Inertia

Provides normalized, momentum-based scrolling across all modern browsers and hardware. Synchronized via requestAnimationFrame loop with GSAP ScrollTrigger so triggers update with microsecond precision during high-velocity scrolls.

Inertial Physics Scroll Synchronization Touch Normalization

Vanilla ES6+ JavaScript

Zero-Framework Core Logic

Zero heavy framework overhead (no React, Angular, or Vue). Pure event delegation, ARIA modal focus management, form validation with RFC-compliant email checking, dynamic mailto generation, and localStorage drawer persistence.

Event Delegation Focus Trap & A11y Zero Virtual DOM Pure ES6 Modules

04 // ARCHITECTURAL HIGHLIGHTS

Feature Engineering Deep-Dive

Detailed technical review of the 6 core features that define the Umer Surti VIP experience.

3D Particle Galaxy & Trails

Interactive WebGL Environment

A responsive WebGL canvas dynamically recalculates aspect ratios on window resize. Light trails use a circular trail buffer with gentle velocity damping to prevent particle drift. Listens for the HTML5 Page Visibility API to pause rendering loops when the browser tab loses focus.

File: js/three-particles.js O(1) Memory Footprint 60 FPS Render Loop

Accessible Case Study Modal

ARIA Compliant Dialog & Focus Trap

Implements strict WAI-ARIA dialog practices: saves the trigger element, moves active focus into the modal, traps keyboard navigation within modal boundaries, binds Escape key dismissal, and locks body scrolling via Lenis to prevent background scroll creep.

File: js/app.js ARIA role="dialog" Keyboard Navigation Lenis.stop() Sync

Cinematic Journey Timeline

Dual & Single Column Responsive Line

Features an ultra-fine vertical metallic bronze spine with glowing circular waypoints. Dynamically pivots from an alternating desktop layout to a streamlined single-column layout on viewports below 992px with zero line overlaps or text clipping.

File: css/style.css GSAP ScrollTrigger Reveal CSS Pseudo-element Spine

Resilient Contact Form

Client Validation & Mailto Fallback

Validates required fields and email format via RFC 5322 regex. Upon submission, constructs a direct RFC-compliant mailto: URL to send messages directly via the user's default email client, eliminating reliance on brittle third-party backend proxies.

File: js/app.js Zero Backend Dependency Instant User Feedback

Interactive Project Showcase

3D Tilt & Metallic Lighting

Project cards respond to pointer coordinates with subtle 3D rotational perspective and dynamic radial gradient specular highlights. Cards feature genuine project imagery, tags, and modal preview triggers.

File: js/app.js Perspective 1000px Specular Lighting

Off-Canvas Mobile Drawer

Touch-Optimized Responsive Drawer

A luxury slide-out menu drawer that handles screen sizes from 320px foldables to modern tablets. Automatically handles aria-expanded toggles, closes upon link navigation or outside click, and synchronizes with body scroll locking.
